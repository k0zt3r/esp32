# Неон на OLED

Шесть исходных idle-кадров пользовательского персонажа Неон скопированы из локального проекта pets/neon/frames/idle. Оригинальный образ: чёрный кот, яркие глаза, технологичная куртка и изогнутый хвост. Исходники питомца не изменяются.

`python tools/pack_neon.py` из корня ESP32-репозитория переводит эти кадры в 64×64, 1 бит на пиксель и создаёт `ThermoDashboard/neon_frames.h`. Для повторной конвертации нужен Pillow (`python -m pip install Pillow`). Для обычной сборки Pillow не требуется: готовый заголовок включён в исходники.

Преобразование использует общую область всех кадров, одинаковый масштаб, контур силуэта и светлые глаза/одежду. Бирюзовый цвет физически не воспроизводится на монохромном OLED. Полный набор занимает 3072 байта Flash. Предпросмотр PNG/GIF сохраняется в локальную `.preview/neon/`.

Слева показывается Неон (~5,6 кадра/с), справа — настоящая температура и состояние Wi-Fi/MQTT. Это порт существующей анимации на микроконтроллер; сетевое управление питомцем не добавлено.
